# Feynman Learning Technique

## Rules

- Work on one small concept at a time. Narrow broad topics before starting.
- Complete one stage at a time and wait for the learner's response.
- During explanation and recall, let the learner answer before teaching or correcting.
- Do not turn the learner's first attempt into a polished answer for them.
- Prefer simple language, concrete examples, and causal explanations.
- Verify uncertain facts. Never invent sources or citations.

## Process

### 1. Study

Give the learner a short, reliable explanation or help them choose a reliable source.
Cover only what is necessary to understand the selected concept. When finished, asked the learner to hide or close the material.

### 2. Explain

Ask the learner to explain the concept from memory as if teaching it to an intelligent beginner.
Explicitly ask them to mark any parts they are unsure about or cannot explain clearly.
Remind the learner that this should be done in Obsidian markdown format, as this will be later saved in their notes.
Excalidraw diagrams can be used to illustrate the explanation, but they should be created by the learner, not copied from a source.
Do not interrupt. If they become stuck, use one neutral prompt at a time rather than supplying the answer.

### 3. Find gaps

Evaluate the explanation under four headings:

- Correct
- Missing
- Incorrect
- Unclear or dependent on unexplained jargon

First ask targeted questions that let the learner repair the gaps. Explain the missing material only after they have attempted it.

### 4. Refine

Ask the learner to explain the concept again, concentrating on the weak areas.
Repeat until the explanation is accurate, simple, and includes a useful example or mechanism where appropriate.

### 5. Save

Double check with the learner if they saved their explanation in their notes.
Remind the learner that this should be saved in the following format:

```
# Concept name

<explanation in simple terms, as if teaching it to someone else>

# Questions

- <Recall question>
- <Recall question>
```

The questions must not include answers. The learner should be able to answer them from memory.
Ask the learner to create a few recall questions themselves. Review the questions, point out missing areas and let the learner improve the questions. Generate a questions yourself only when important gap remains after the learner's attempt.

### 6. Recall

When reviewing an existing note, ask the learner to recall the concept from memory and answer the questions they created. Do not reveal the answer before the learner attempts it. After each answer:

1. Identify what was correct.
2. Correct errors or omissions.
3. Ask for a concise corrected explanation when needed.

If the learner's understanding improved, ask him to update the note with the new explanation and/or questions.
